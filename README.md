# FruitBallerz ##
🎮 O Jogo
O projeto **FruitBallers** é uma aplicação desenvolvida em Swift para o ecossistema Apple. O código fonte está estruturado no Xcode (`FruitBallers.xcodeproj` e `project.xcworkspace`), com a gestão de estado da interface a suportar utilizadores específicos.

## 🛠️ Tecnologias e Ferramentas
* **Ambiente de Desenvolvimento:** Xcode
* **Linguagem Principal:** Swift (`AppDelegate.swift`)
